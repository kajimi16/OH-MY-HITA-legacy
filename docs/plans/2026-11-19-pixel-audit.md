## 3. 本轮补做的像素验收

### 3.1 更多页抽屉

问题：旧抽屉只有文字与箭头，宽度 300dp、头像 96dp、行高约 62dp；
上游是 260dp 抽屉、72dp 头像、48dp 行。

修复后测量：

| 项目 | 上游 | 当前 |
|---|---:|---:|
| 抽屉宽度 | 683 px（260dp） | 683 px |
| 头像 bounds | `[644,218][832,406]` | `[644,218][832,406]` |
| 行高 | 126 px（48dp） | 126 px |
| 首行中心 | ≈815 px | ≈819 px |
| 标题/用户名 bounds | 449 / 548 | 449 / 548 |

差异（排除状态栏，tolerance 10）：

| 区域 | 差异 |
|---|---:|
| 抽屉面板 | **3.257%** |
| 抽屉行 | **6.666%** |
| 抽屉头部 | **8.940%** |

结论：**结构、尺寸、关键 bounds 通过；像素未达 1%**。残差集中在：
`NavigationView` 默认字体栅格化、菜单图标内边距、头像 PNG 解码；继续调是过拟合，
本轮停止。抽屉不是 7.1 的页面阈值对象，不能据此声明整页通过。

### 3.2 成绩分析插件页

上游页：`ShenzhenGradeAnalysisActivity`，标题“个人成绩明细”，右上刷新；
未登录态是底部白色卡片“请先连接深圳 Web 教务”+“连接 Web 教务”按钮。

当前页：统一 `PluginUiActivity` Toolbar 已存在，但标题仍是插件名“成绩分析”，
无刷新动作；未登录态是页首单行文本“未登录教务，请先在侧边栏登录”。

像素差异（排除 63px 状态栏，tolerance 10）：

未登录卡片结构。需要插件声明页面标题/动作或宿主提供通用空态组件，不能靠继续画文字修。

## 5. 复审结论

1. 已关闭项维持原状态，不重复优化 HITA-L 三页、资讯残差、视频 429、header/dock。
2. 更多页抽屉完成结构/尺寸/bounds 对齐；像素 3.257%，记录为已知残差。
3. 成绩插件页未通过像素验收；TopAppBar 已补，但标题/动作/空态结构仍不同。
4. 其余未比较对象要么没有上游等价页面，要么缺少登录态/等价数据，不能记为通过。

## 6. 下一步优先级

1. 成绩插件页：定义插件页面标题与工具栏动作契约，统一未登录卡片。
2. Shell 资讯详情/门户登录：构造上游同数据态后再做像素。
3. 更多页内容区：构造与上游相同的课表/登录态后重算 6.25%。
4. 迁移的 EAS 子页面：抽样做像素，而不是继续声称“结构一致”。
